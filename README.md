# BakCity RP (БакСити РП)

## Project Overview (Обзор проекта)
BakCity RP is an open-world multiplayer role-playing game project for mobile devices, featuring custom maps, vehicle mechanics, and interactive roleplay elements.
*(BakCity RP — бұл мобильді құрылғыларға арналған ашық әлемдегі көп ойыншылы рөлдік ойын жобасы; онда арнайы карталар, көлік механикасы және интерактивті рөлдік элементтер бар.)*

## Features (Особенности)
- Open-world multiplayer roleplay *(Ашық әлемдегі көп ойыншылы рөлдік ойын)*
- Custom maps and environment *(Арнайы карталар мен орта)*
- Vehicle mechanics and customizable controls *(Көлік механикасы және бапталатын басқару элементтері)*
- Server backend (`server.js`) and web/mobile interface (`index.html`) *(Сервер бөлігі — `server.js` және интерфейс — `index.html`)*

## Setup Instructions (Инструкция по установке)
1. Clone or download the repository *(Репозиторийді клондаңыз немесе жүктеп алыңыз)*
2. Install dependencies if needed *(Қажет болса тәуелділіктерді орнатыңыз)*
3. Run `server.js` and open `index.html` in your environment *(Ортаңызда `server.js` файлын іске қосып, `index.html` файлын ашыңыз)*
